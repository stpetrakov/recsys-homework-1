# Рекомендательные системы — домашнее задание 1

**Студент: Петраков Степан Дмитриевич.**

Пять самостоятельно реализованных моделей для персональных top-10 рекомендаций:
ItemKNN, iALS, EASE, FM с историческими метапризнаками и ALS с авторским целевым сигналом.
Обучение, предсказания, ранжирование и метрики написаны в этом репозитории.

## Данные

**Amazon Reviews 2018 — Digital Music, 5-core.**
[Первоисточник](https://nijianmo.github.io/amazon/index.html) ·
[Официальный файл](https://mcauleylab.ucsd.edu/public_datasets/data/amazon_v2/categoryFilesSmall/Digital_Music_5.json.gz).

Исходно 169 781 отзыв; после удаления повторных user–item пар — 145 292.
Детерминированная подвыборка содержит **107 777 взаимодействий, 16 427 пользователей,
6 000 товаров**. Товары выбираются по частоте до границы train, равенства разрешаются
по ASIN. Для повторной пары сохраняется первый отзыв. Названия пользователей и тексты
отзывов не используются. Сами данные в репозитории отсутствуют.

Цитирование: Jianmo Ni, Jiacheng Li, Julian McAuley. *Justifying Recommendations
using Distantly-Labeled Reviews and Fine-Grained Aspects*. EMNLP 2019.
[Статья](https://aclanthology.org/D19-1018/).

## Запуск

Python **3.12**, CPU; при запуске эксперимента используется 2 вычислительных потока.
Рекомендуется 4 GB свободной оперативной памяти или больше для плотного решения EASE.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m pytest -q
python run_notebook.py
```

В Windows активируйте `.venv\Scripts\activate` вместо `source ...`.
Первое выполнение скачивает около 20 MB в `data/` и проверяет SHA-256.
Если HTTPS-доступ ограничен окружением, скачайте официальный файл вручную
в `data/Digital_Music_5.json.gz`; проверка контрольной суммы остаётся обязательной.
Проверку TLS отключать не нужно.

`run_notebook.py` запускает все ячейки **experiments.ipynb**, сохраняя таблицы,
графики и выводы. Альтернатива без визуализаций: `python experiment.py`.
Не запускайте оба процесса одновременно в одной папке: они записывают одинаковые результаты.

## Протокол

- Train: до **2015-12-29 UTC**; validation: до **2016-09-28 UTC**; test: остаток периода.
- Единое определение релевантности: первая оценка **≥4**.
- Кандидаты: все 6 000 товаров, кроме всех известных пользователю товаров, включая низкие оценки.
- Общая warm-start когорта для всех моделей внутри каждой фазы. Новые пользователи,
  объекты вне фиксированного каталога и пользователи без доступных релевантных товаров
  учитываются в аудите исключений.
- Настройки выбираются исключительно по **NDCG@10 на validation**. После их фиксации
  модели переобучаются на train+validation. Дополнительно считаются **Recall@10** и покрытие.
- Seed=42; одинаковые разбиения и правила tie-break. При оценке негативы не сэмплируются.

Кастомный ALS меняет **целевой сигнал**, сохраняя confidence базового iALS:
`clip((rating - 3) / 2, -1, 1) * (0.5 + 0.5 * 2**(-age_days / 365))`.
Включены контроль при тех же гиперпараметрах базового iALS и абляция FM без метапризнаков.
Формулы, основания методов и ограничения интерпретации приведены в ноутбуке.

## Результаты выполненного эксперимента

| Модель | NDCG@10 | Recall@10 | Coverage@10 |
|---|---:|---:|---:|
| ItemKNN | 0.02287 | 0.03675 | 71.15% |
| iALS | 0.02178 | 0.03347 | 16.28% |
| EASE | 0.02778 | 0.04360 | 62.35% |
| FM | 0.00785 | 0.01430 | 9.90% |
| CustomALS | 0.02248 | 0.03532 | 15.90% |

Общая test-когорта: **1 897 пользователей**, 4 962 релевантные пары. EASE лидирует на test; на validation лидировал CustomALS. Это не использовалось для дополнительного подбора.

При фиксированных настройках метапризнаки FM изменили NDCG@10 на **−0.01097** (95% парный bootstrap: [−0.01474; −0.00701]); кастомный таргет ALS — на **+0.00033** ([−0.00256; +0.00328]). Улучшение кастомного таргета надёжно не подтверждено.

Проверено: **9 unit-тестов**, **10 выполненных кодовых ячеек без ошибок**, **6 графических выводов**. Подбор: 19 конфигураций. При двух полных запусках все 21 итоговые метрики совпали точно. Полные настройки и результаты — в `results/` и ноутбуке.

## Ограничения

Отзывы не равны покупкам или показам. Выбор 5-core и популярных товаров смещает выборку;
результат относится к warm-start и фиксированному каталогу. Длинное test-окно не моделирует
обновление истории внутри периода. Один seed и небольшой поиск не гарантируют оптимальность;
bootstrap отражает только вариативность состава пользователей при фиксированном обучении.

MovieLens, Netflix Prize и Last.fm не используются. Список датасетов семинаров не предоставлен:
при сдаче необходимо сверить, что Digital Music не использовался на семинаре курса.
